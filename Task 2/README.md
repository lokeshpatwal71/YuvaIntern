# Hands-On Data Lab Implementation

A beginner-friendly data analysis project built for the **Yuva Intern** internship: set up a Python data-science environment (Python, Jupyter Notebook, pandas, NumPy, Matplotlib, Seaborn) and complete practical exercises in data manipulation, visualization, exploratory data analysis (EDA) and basic statistics.

> **Dataset note:** the dataset in this project is **synthetic** (generated by `src/generate_dataset.py`). It is modelled on the layout of the public Kaggle *Supermarket sales* dataset but is not real company data. See [`data/README.md`](data/README.md).

## About the Project
The project analyses 1000 supermarket invoices from three branches over 90 days (01 January 2025 to 31 March 2025). It follows the complete workflow of a small analysis project: load the data, check quality, clean it, manipulate it with pandas, explore it with 10 questions, visualize it with 8 charts, calculate correlations and statistics, and write insights.

## Objectives
1. Set up a data science environment using Python, Jupyter Notebook and the required libraries.
2. Complete practical exercises in data manipulation, data visualization, exploratory data analysis and basic statistical analysis.

## Dataset
| Item | Details |
|---|---|
| Name | Supermarket Sales (synthetic version) |
| Rows x columns | 1006 x 17 raw (1000 unique invoices after cleaning) |
| Represents | One row per customer invoice in a 3-branch supermarket chain |
| Important columns | `Product line`, `Branch`, `City`, `Customer type`, `Gender`, `Unit price`, `Quantity`, `Total`, `Date`, `Time`, `Payment`, `Rating` |

Data-quality problems included on purpose and fixed in the project: 12 blank ratings, 6 duplicate invoices, 8 spellings of 3 payment methods, and text-typed dates.

## Analysis Performed
* Initial exploration: `head`, `tail`, `shape`, `columns`, `info`, `describe`, `dtypes`
* Data quality checks: missing values, duplicates, data types, inconsistent text, range and formula checks, outliers (IQR rule)
* Data cleaning: rename columns, standardise text, remove duplicates, fill missing ratings, convert dates, drop redundant columns, validation checks
* Data manipulation: selecting, filtering, sorting, new columns, `value_counts`, aggregation, `groupby`, pivot table
* EDA: 10 questions about revenue, product lines, branches, payments, trends, peak hours, customer types and ratings
* Correlation analysis with a heatmap
* Basic statistics: mean, median, mode, standard deviation, min, max, quartiles, skewness, outliers

## Key Findings
(All values come from the synthetic dataset.)
* Revenue after cleaning: **Rs. 2,776,985.72** from 1000 invoices; average invoice Rs. 2,776.99, median Rs. 2,277.04 (right-skewed data).
* **Home and lifestyle** is the top product line (Rs. 640,873, 23.1% of revenue); **Food and beverages** is the lowest (Rs. 222,858).
* Branch C (Bengaluru) has the highest revenue (Rs. 965,691); Branch A (Mumbai) the lowest (Rs. 851,038).
* Payment methods are used almost equally (34.5%, 33.0%, 32.5%).
* Members spend about 19% more per invoice than Normal customers, because they buy more items.
* Peak hours are lunchtime (13:00) and the evening (18:00 to 20:00); weekends bring 38.1% of revenue.
* Revenue per day is flat over the three months (no growth trend).
* Ratings are not related to spending (correlation 0.03).

The project shows a complete beginner-level analysis workflow in Python. Cleaning the data was essential (duplicates would have overstated revenue), and the combination of pandas summaries and charts made the patterns easy to see. The dataset is synthetic, so the findings describe this file only.
