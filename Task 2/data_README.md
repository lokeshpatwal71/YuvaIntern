# Dataset: `dataset.csv`

## Important: this dataset is synthetic
`dataset.csv` was **generated by a Python program** (`src/generate_dataset.py`, fixed random seed 2025). It is **not** data from a real supermarket. Its columns and layout are modelled on the public Kaggle *Supermarket sales* dataset (https://www.kaggle.com/aungpyaeap/supermarket-sales), but none of its rows come from that dataset.

A few typical data-entry problems were added **on purpose** so that the data-cleaning step has real work to do:

| Problem added on purpose | Amount |
|---|---|
| Blank values in `Rating` | 12 rows |
| Same payment method typed differently (`cash`, `Cash `, `ewallet`...) | 8 spellings for 3 payment methods |
| Invoices entered twice (exact duplicate rows) | 6 rows |

Everything else (prices, quantities, totals, dates, times) is internally consistent.

## Size
* **1006 rows x 17 columns** (raw file, including the 6 duplicates)
* **1000 unique invoices** after cleaning
* Period: 01 January 2025 to 31 March 2025 (90 days), 3 branches (A, B, C)

## Data dictionary

| Column (raw name) | Meaning | Type |
|---|---|---|
| `Invoice ID` | Unique invoice number (INV-00001 ...) | text |
| `Branch` | Branch code: A, B or C | text |
| `City` | City of the branch (A = Mumbai, B = Delhi, C = Bengaluru) | text |
| `Customer type` | `Member` (has a membership card) or `Normal` | text |
| `Gender` | Female or Male | text |
| `Product line` | Product category (6 categories) | text |
| `Unit price` | Price of one item in Rs. | decimal |
| `Quantity` | Number of items bought (1 to 10) | integer |
| `Tax 5%` | 5% tax on the invoice, in Rs. | decimal |
| `Total` | Invoice amount including tax, in Rs. (= cogs + tax) | decimal |
| `Date` | Invoice date as text in month/day/year format (e.g. 1/5/2025) | text |
| `Time` | Invoice time as text, 24-hour (e.g. 13:45) | text |
| `Payment` | Cash, Credit card or Ewallet | text |
| `cogs` | Unit price x quantity, before tax | decimal |
| `gross margin percentage` | Constant value (4.761904762); carries no information | decimal |
| `gross income` | Identical to `Tax 5%`; carries no extra information | decimal |
| `Rating` | Customer rating from 1 to 10 | decimal |

## Using the real Kaggle dataset instead (optional, not tested here)
The public dataset is "Supermarket sales" by Kaggle user Aung Pyae: 1000 rows, 17 columns, three branches, January to March 2019 (https://www.kaggle.com/aungpyaeap/supermarket-sales). You can download it from Kaggle (a free Kaggle account is needed), save it as `data/dataset.csv` and run the notebook again.

Please note:
* **This project was run and tested only on the synthetic file.** I did not run it on the real file, so the code may need small changes (for example the date format string in the date-conversion step, or the payment spellings).
* All numbers written in the notebook text, README and report belong to the synthetic file. With the real file they will be different, so those sentences would have to be re-written from your new outputs.
